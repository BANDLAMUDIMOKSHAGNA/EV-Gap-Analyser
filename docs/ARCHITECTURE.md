# System Architecture — EV Gap Analyser

The **EV Gap Analyser** is a decision-support platform designed for city planners, municipal administrative bodies (GVMC), power distribution companies (DISCOMs / APEPDCL), and charge point operators (CPOs). It models spatial charging accessibility, predicts charging demand, detects supply gaps, ranks candidate sites via multi-criteria decision analysis (AHP + TOPSIS), and solves maximal-coverage location problems under budget constraints using Google OR-Tools (CP-SAT).

## 2. Design Principles

1. **City-Agnostic Core**: Every city is fully parameterized via a single configuration file (`config/cities/{city_id}.json`) specifying the bounding polygon, RTO registration office codes, and regional zones.
2. **Data Honesty & Traceability**: No real statistics are fabricated. In `DATA_MODE=demo`, all records are generated by transparent, documented scripts (`pipelines/generate_sample_data.py`). Every number is traceable to its source and date via `GET /api/v1/datasets`.
3. **Graceful Routing Abstraction**: Clean `RoutingProvider` interface with an automatic fallback from containerized OSRM (`OsrmProvider`) to calibrated urban detour approximation (`ApproxProvider`), flagged explicitly in all API responses and UI badges.
4. **Explainable Recommendations**: Rather than a black-box ranking, TOPSIS closeness coefficients are decomposed into per-criterion positive/negative separation contributions, directly powering the &quot;Why this site?&quot; card.
5. **Dual Storage Mode**: Works seamlessly in enterprise cloud deployments with PostgreSQL 16 + PostGIS, while supporting portable zero-dependency SQLite spatial storage for local development and offline field evaluations.
